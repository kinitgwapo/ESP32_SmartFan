# Note
This project requires you to have your own hosted Firebase Realtime Database & Firebase Webapp if you wish to use this project with your own credentials. You can even modify the webpage design by simply changing the HTML & CSS Files with ease, but you might have to understand the JavaScript files if you want to change the entire logic.

"controlLogic_Template.js" contains the template for "controlLogic.js" but does not have the Firebase API keys for security purposes. You are required to create a loginLogic.js & controlLogic.js to their respective folder location with the contents of those Templates and Firebase API keys.
